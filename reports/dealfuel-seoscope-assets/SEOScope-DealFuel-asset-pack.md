## 1. Product description

**Product website:** https://seoscope.dev

**Product definition**
SEOScope is an on-page SEO audit tool with a REST API. Give it any URL and it returns a 0-100 score with a specific, actionable fix for every finding — titles, meta descriptions, heading hierarchy, Open Graph, JSON-LD structured data, links and page weight. It runs in the browser for people and over the API for pipelines, with no crawl credits to budget and no software to install.

**Features**

- On-page audit of any public URL, scored 0-100 with per-category breakdown
- Title and meta-description checks (presence, length, duplication)
- Heading hierarchy validation (H1 presence, order, nesting)
- Open Graph and Twitter card validation — the fields that decide how a link looks when shared
- JSON-LD / structured-data validation
- Link analysis, including broken-link detection
- A concrete recommended fix attached to every finding, not just a flag
- Bulk audits — up to 25 URLs in a single API call (Premium and above)
- Scheduled monitoring — a site is re-audited automatically and you are emailed the moment the score moves (Premium and above)
- Webhook delivery for every alert, so results land in the tools a team already uses
- REST API with an instant key, full OpenAPI documentation at /docs
- Dashboard for audit history and key management

**Highlights**

- A score you can act on: every point lost comes with the fix that recovers it.
- Seconds, not a crawl queue. One URL, one request, one answer.
- No crawl credits and no per-page metering on the lifetime tier — the limit is the monthly audit count, and on lifetime there isn't one.
- API-first. Anything that can make an HTTPS request can audit a page, so it drops straight into CI, a cron job, or a no-code automation.
- Built by a developer who ships SaaS, for the same job: knowing a deploy did not quietly break the SEO basics.

**Specifications**

- Delivery: hosted web app + REST API. Nothing to install, nothing to self-host.
- Authentication: API key, issued instantly on signup or on redeeming a code.
- Output: JSON over HTTPS. Full OpenAPI spec published at https://seoscope.dev/docs
- Infrastructure: Vercel, EU/global edge. HSTS, strict Content-Security-Policy with nonce, no third-party script injection.
- Input: any publicly reachable URL.
- Privacy: a signed DPA is available on request; see https://seoscope.dev/dpa

**Plan features (Enterprise Lifetime)**

- REST API at the highest rate limit offered

**Target audience**

- Freelancers and agencies auditing client sites — fast enough to run during a sales call, detailed enough to hand over as a deliverable.
- SEO consultants who want the structured-data and Open Graph checks without a full enterprise crawler subscription.

## 2. Deal terms — your ten questions

**1. How to activate the license keys and start a subscription**
The buyer goes to **https://seoscope.dev/redeem**, enters the code and their email address, and submits. The account is created and upgraded to Enterprise Lifetime immediately — there is no waiting period and no manual approval from our side. The API key is shown on screen and emailed at the same time. If they already have a free SEOScope account on that email, that same account is upgraded rather than a duplicate being created.

**2. Validity of the activation code — within how many days must it be redeemed?**
There is no deadline. SEOScope codes carry no expiry date, and the product has no mechanism that expires them — I verified this in the code before answering. A buyer can sit on a code indefinitely and it will still work.

**3. Is lifetime access available?**
Yes. That is exactly what this deal is: one payment, permanent access to the top tier.

**4. Are lifetime updates available? Free? Automatic?**
Yes, free, and automatic. SEOScope is a hosted service, so there are no versions to install — every user is always on the current build, and every feature shipped after purchase is included at no extra cost. There is no "upgrade to the new version" charge because there is no new version to buy.

**5. Is lifetime support available? Free or paid? Support email**
Yes, free, for the lifetime of the account. Support email: **hello@seoscope.dev**. Target response is one business day, answered by a person, in writing.

**6. Is this deal for new users only?**
No. An existing free user can redeem a code on their current account and it is upgraded in place, keeping their audit history and existing API key.

**7. How many users can use the license key/coupon code?**
One. Each code is single use and activates one account. 100 codes means 100 accounts.

**8. Are the coupon codes stackable?**
No, and stacking would have no effect even if attempted: the code grants the top tier with unlimited audits, so a second code on the same account would have nothing left to raise. Each code is intended for a separate account.

**9. What are the system requirements?**
None beyond a modern browser and an internet connection. For API use, anything that can make an HTTPS request — curl, any language, any automation platform. No OS requirement, no install, no plugin.

**10. Can this product be accessed on all devices — mobile, desktop, tablet?**
Yes. The interface is responsive and works on phone, tablet and desktop, and the API is device-independent.
